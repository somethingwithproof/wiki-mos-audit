## ይህ ለምን ተፈጠረ

Wikipediaን አርማለሁ። ያለማቋረጥ ባይሆንም፣ አንድ ዓይነት ድግግሞሽ ማስተዋል እስክጀምር ድረስ በበቂ ሁኔታ አርማለሁ: ለማጽዳት አንድ መጣጥፍ በከፈትኩ ቁጥር ተመሳሳይ የአእምሮ ማረጋገጫ ዝርዝርን እፈትሽ ነበር። ቀኖቹ ወጥ ናቸው? አሻሚ ቃላት አሉ? አንድ ሰው በማጣቀሻዎች ውስጥ ባዶ URLዎችን ትቷል? የ«See also» ክፍል ተለጥጧል? የታችኛው ክፍል አርዕስቶች በትክክለኛው ቅደም ተከተል ናቸው?

ተመሳሳይ ደርዘን ችግሮችን በተከታታይ ሦስት ወይም አራት ጊዜ በእጅ ከፈተሽኩ በኋላ አንድ ስክሪፕት ጻፍኩ። ያ ስክሪፕት አደገ። አሁን በእጅ የምሠራቸውን 30+ ነገሮች ይፈትሻል፣ እና በድካም የተሞላ የማክሰኞ ምሽት ልዘነጋቸው የምችላቸውን ነገሮች ይይዛል።

ይህ የአርትዖት ውሳኔን አይተካም። የቅድሚያ መለያ መሣሪያ ነው። ምን መጻፍ እንዳለብዎ ሳይሆን የት መመልከት እንዳለብዎ ይነግርዎታል።

## አጠቃቀም

ቀጥታ የWikipedia መጣጥፍን ኦዲት ያድርጉ:

```
wiki-mos-audit "Gettysburg Address"
```

ከURL ኦዲት ያድርጉ:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

የአካባቢ wikitext ፋይልን ኦዲት ያድርጉ:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

የwikitext ፋይሎች ማውጫን በቡድን ኦዲት ያድርጉ:

```
wiki-mos-audit --dir ./articles/
```

የAPI ፍተሻዎችን ይዝለሉ (ከመስመር ውጭ ሁነታ):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### የውጤት ቅርጸቶች

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### አማራጭ ፍተሻዎች

እነዚህ ዘገምተኛ ስለሆኑ ወይም የአውታረ መረብ መዳረሻ ስለሚፈልጉ በነባሪነት ጠፍተዋል:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### ራስ-ሰር ጥገና

ደህንነታቸው የተጠበቀ ሜካኒካዊ ጥገናዎች (ባዶ ቦታ፣ አቀራረጽ) በራስ ሰር ሊተገበሩ ይችላሉ:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

ሳይጽፉ ቅድመ-እይታ ይመልከቱ:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### የልዩነት ሁነታ

የአካባቢ wikitextን ከቀጥታው ስሪት ጋር ያወዳድሩ:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### ውቅር

ገደቦችን ለማስተካከል ወይም የተወሰኑ ፍተሻዎችን ለማሰናከል `.wiki-mos-audit.toml` ፋይል ይፍጠሩ:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

በግልጽ ያስተላልፉት:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### የቋንቋ አካባቢያዊነት

የCLI እገዛ፣ ምርመራዎች እና የጽሑፍ/HTML ሪፖርት ገጽታዎች ምንም ተጨማሪ ጥገኝነቶች ሳይኖራቸው 45 ቋንቋዎችን (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) ይደግፋሉ። የቋንቋ አመራረጥ መጀመሪያ `--lang`ን (የWikipedia እትምን ከሚመርጠው `--language` የተለየ)፣ ከዚያ `LC_ALL`፣ `LC_MESSAGES` እና `LANG`ን ይፈትሻል፣ ወደ `en` በመመለስ። የJSON ውጤት ቁልፎች እና የwikitext አብነቶች ሳይለወጡ ይቆያሉ።

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## የPython API

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
