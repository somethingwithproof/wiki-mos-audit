Ngwa nnyocha mbụ nke [Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) maka edemede Wikipedia.

## Ihe mere nke a ji dị

Ana m edezi Wikipedia. Ọ bụghị mgbe niile, mana o zuru oke nke na m malitere ịhụ otu ụkpụrụ: oge ọ bụla m mepere edemede iji dozie ya, ana m agbaso otu ndepụta nnyocha uche ahụ. Ụbọchị ha ọ dakọtara? O nwere okwu mgbagwoju anya (weasel words)? O nwere onye hapụrụ URL efu na ntụaka? Ngalaba See also ọ buru ibu karịa? Ngalaba dị n'ala edemede ha ọ dị n'usoro ziri ezi?

Mgbe ugboro atọ ma ọ bụ anọ m jiri aka nyochaa otu nsogbu iri na abụọ ahụ n'usoro, edere m skript. Skript ahụ toro. Ugbu a ọ na-enyocha ihe karịrị 30 m na-eji aka eme, ma ọ na-achọpụta ihe m gaara eleghara anya na mgbede Tuzdee ike gwụrụ.

Nke a abụghị ihe ga-anọchi mkpebi nchịkọta akụkọ. Ọ bụ ngwaọrụ nhazi mbụ (triage). Ọ na-agwa gị ebe ị ga-ele anya, ọ bụghị ihe ị ga-ede.

## Ihe ọ na-enyocha

**Ụdị ederede na ụda olu**
- Okwu mgbagwoju anya (MOS:WEASEL), okwu nganga na-enweghị ihe akaebe (MOS:PEACOCK)
- Okwu oge dabere na mgbe ("recently", "currently") nke na-efunahụ izi ezi ka oge na-aga
- Akara ọdịnaya AI mepụtara: ikwubiga okwu oke banyere isi mmalite n'ahụ edemede (WP:AISIGNS), nhazi okwu dị ka edemede echiche (WP:NOTESSAY)
- Nnyocha okwu MOS:INDIGENOUS
- Nhazi aha MOS:AVIATION
- Nkwupụta ndị nwụrụ anwụ enweghị ntụaka MOS:MILITARY

**Nhazi edemede**
- Ogologo mmalite na ọnụọgụ paragraf (MOS:LEAD)
- Usoro ngalaba megide MOS:LAYOUT
- Ngalaba dị mkpụmkpụ ma ọ bụ nke na-etozughị etozu
- Ngalaba enweghị ntụaka (okwu 100+, enweghị `<ref>`)
- Mbuli elu karịrị akarị nke ngalaba See also
- URL mpụga efu n'ahụ edemede
- Ọnụọgụ ndebiri okwu e kwuru (quote template)

**Ntụaka na nrụtụaka**
- URL efu n'ime mkpado `<ref>` (enweghị ndebiri ntụaka)
- Nyocha izi ezi ọnụọgụ nlele ISBN
- URL e mebiri emebi n'ime ndebiri ntụaka
- Njikọ mpụga nwụrụ anwụ (nhọrọ, na-ewe oge)

**Ụdịrị na njikọ**
- Ụdịrị na-efu efu
- Ogo ụdịrị (ụdịrị dị ole na ole, nke sara mbara karịa)
- Nchọpụta njikọ uhie (njikọ wiki na-eduga n'edemede na-adịghị adị)
- Ụdịrị njikọ uhie
- Njikọ ibe nkọwa dị iche (disambiguation)
- Njikọ karịrị akarị (MOS:OVERLINK)

**Infobox**
- Ọnụọgụ paramita na ọnụọgụ ndepụta (nchọpụta mbuli elu karịrị akarị)
- Paramita a na-atụkarị anya ha na-efu efu
- Akara infobox MOS:MILHIST

**Ndị ọzọ**
- Ogo nkọwa mkpirikpi (na-efu efu, ogologo karịa, dakọtara na isiokwu)
- Ndekọ ndebiri nlekọta
- Ịdị ọcha njikọ ọrụ nwanne (MOS:SISTER)
- Nchọpụta edemede nọ naanị ya (enweghị njikọ wiki na-abata)
- Nchọpụta njikọ azụ nwere ike ịdị
- Ụkpụrụ isiokwu usoro oge/liveblog

Nnyocha ọ bụla na-emepụta nsogbu nwere ọkwa ịdị njọ (dị ala/etiti/dị elu) yana mwepụ akara. Edemede dị ọcha na-enweta akara 100.

## Ojiji

Nyochaa edemede Wikipedia dị ndụ:

```
wiki-mos-audit "Gettysburg Address"
```

Nyochaa site na URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Nyochaa faịlụ wikitext dị n'igwe gị:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Nyochaa ndekọ faịlụ nke faịlụ wikitext ọtụtụ n'otu oge:

```
wiki-mos-audit --dir ./articles/
```

Wụfee nnyocha API (ọnọdụ na-enweghị ịntanetị):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Ụdị nsonaazụ

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Nnyocha nhọrọ

A gbanyụrụ ndị a na ndabara n'ihi na ha na-adị nwayọọ ma ọ bụ chọọ nnweta netwọk:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Ndozigharị onwe

Enwere ike itinye ndozigharị nkịtị dị nchebe (oghere efu, nhazi) na-akpaghị aka:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Nhụcha mbụ na-edeghị:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Ọnọdụ Diff

Tụlee wikitext dị n'igwe gị megide ụdị dị ndụ:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Nhazi

Mepụta faịlụ `.wiki-mos-audit.toml` iji gbanwee oke ma ọ bụ gbanyụọ nnyocha ụfọdụ:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Nyefee ya kpọmkwem:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Nhazi asụsụ mpaghara

Enyemaka CLI, ozi nnyocha, na nhazi mkpesa ederede/HTML na-akwado asụsụ mpaghara 45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) na-enweghị ihe ndabere ọzọ ọ bụla. Mkpebi asụsụ na-enyocha `--lang` (dị iche na `--language`, nke na-ahọrọ mbipụta Wikipedia), wee `LC_ALL`, `LC_MESSAGES`, na `LANG`, wee laghachi na `en`. Igodo nsonaazụ JSON na ndebiri wikitext anaghị agbanwe.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## Python API

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
