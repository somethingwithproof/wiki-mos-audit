Mpanamarina dingana voalohany araka ny [Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) ho an'ny lahatsoratra Wikipedia.

## Ny anton'ny fisian'ity fitaovana ity

Manitsy lahatsoratra ao amin'ny Wikipedia aho. Tsy isan'andro akory, fa ampy nahitako lamina miverimberina: isaky ny manokatra lahatsoratra hodiovina aho, dia ny lisitra fanamarinana ao an-tsaina ihany no averiko. Mirindra ve ny daty? Misy teny manjavozavo ve? Nisy namela URL miboridana tao amin'ny loharano ve? Mibontsina loatra ve ny fizarana Jereo koa? Mifanaraka amin'ny filaharana marina ve ireo fizarana farany ambany?

Taorian'ny fanintelony na faninefany nikarohana tanana ireo olana am-polony mitovy misesy, dia nanoratra script aho. Nitombo izany script izany. Ankehitriny izy dia manamarina zavatra mihoatra ny 30 izay fanaoko tanana, ary mahatratra zavatra mety ho adinoko amin'ny hariva talata mahareraka.

Tsy manolo ny fitsarana ara-panontana ity. Fitaovana fanasokajiana voalohany izy. Milaza aminao ny toerana tokony hojerena izy, fa tsy ny zavatra tokony hosoratana.

## Ny zavatra hamarininy

**Fomba fanoratra sy feo**
- Teny manjavozavo (MOS:WEASEL), teny fideraderana tafahoatra (MOS:PEACOCK)
- Fiteny momba ny fotoana tsy raikitra ("vao haingana", "ankehitriny") izay mora lany andro
- Famantarana votoaty noforonin'ny AI: fanondroana tafahoatra ao amin'ny vatan-dahatsoratra (WP:AISIGNS), fiteny toy ny lahatsoratra fanehoan-kevitra (WP:NOTESSAY)
- Fanamarihana voambolana MOS:INDIGENOUS
- Fandrafetana anarana MOS:AVIATION
- Filazana isan'ny maty na naratra tsy misy loharano MOS:MILITARY

**Rafitra**
- Halavan'ny teny fampidirana sy isan'ny andalana (MOS:LEAD)
- Filaharan'ny fizarana araka ny MOS:LAYOUT
- Fizarana fohy na tsy ampy fivelarana
- Fizarana tsy misy loharano (teny 100+, tsy misy `<ref>`)
- Fizarana Jereo koa mibontsina loatra
- URL ivelany miboridana ao amin'ny vatan'ny lahatsoratra
- Habetsahan'ny lasitra tsongan-kevitra

**Loharano sy tsongan-kevitra**
- URL miboridana ao anatin'ny marika `<ref>` (tsy misy lasitra fanondroana)
- Fanamarinana ny tarehimarika fanamarinana ISBN
- URL tsy ara-dalàna ao amin'ny lasitra tsongan-kevitra
- Rohy ivelany maty (azo safidiana, miadana)

**Sokajy sy rohy**
- Sokajy tsy ampy
- Kalitaon'ny sokajy (tsy ampy sokajy, malalaka loatra)
- Fahitana rohy mena (rohy wiki mankany amin'ny lahatsoratra tsy misy)
- Sokajy rohy mena
- Rohy mankany amin'ny pejy fanavahana hevitra
- Fampiasana rohy tafahoatra (MOS:OVERLINK)

**Infobox**
- Isan'ny masontsivana sy habetsahan'ny lisitra (fahitana fibontsinana)
- Masontsivana andrasana matetika nefa tsy ao
- Famantarana infobox MOS:MILHIST

**Hafa**
- Kalitaon'ny famaritana fohy (tsy misy, lava loatra, mitovy amin'ny lohateny)
- Lisitry ny lasitra fikojakojana
- Fahadiovan'ny rohy mankany amin'ny tetikasa rahavavy (MOS:SISTER)
- Fahitana lahatsoratra kamboty (tsy misy rohy wiki miditra)
- Fahitana rohy mety hampifandraisina avy any ivelany (backlinks)
- Lamina lohateny toy ny tantara misesy na liveblog

Ny fanamarinana tsirairay dia mamoaka olana misy ambaratongan'ny hamafiny (ambany/antonony/avo) miaraka amin'ny fanesorana isa. Mahazo isa 100 ny lahatsoratra madio.

## Fametrahana

```
pip install .
```

Fiankinan-doha takiana ny mwparserfromhell. Manome famakafakana wikitext mifototra amin'ny AST izy mba hahazoana fahitana marina ny lasitra, lohateny, ary rohy wiki. Raha tsy azo atao ny manambatra (compile) azy (tsy misy mpandika C), dia miverina mandeha ho azy amin'ny famakafakana mifototra amin'ny regex ny fitaovana.

Ho an'ny fampandrosoana:

```
pip install -e '.[dev]'
```

## Fampiasana

Hanamarina lahatsoratra Wikipedia mivantana:

```
wiki-mos-audit "Gettysburg Address"
```

Hanamarina avy amin'ny URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Hanamarina rakitra wikitext eo an-toerana:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Hanamarina mitambatra laha-tahiry misy rakitra wikitext:

```
wiki-mos-audit --dir ./articles/
```

Handingana ny fanamarinana API (fomba tsy mampiasa aterineto):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Endriky ny vokatra

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Fanamarinana azo safidiana

Mikatona araka ny mahazatra ireto satria miadana na mila fidirana amin'ny tambajotra:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Fanitsiana mandeha ho azy

Azo ampiharina mandeha ho azy ireo fanitsiana ara-teknika azo antoka (elanelana fotsy, fandrafetana):

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Hijery mialoha nefa tsy manoratra:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Fomba fampitahana (Diff)

Ampitahao amin'ny dikan-teny mivantana ny wikitext eo an-toerana:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Fanefena

Mamorona rakitra `.wiki-mos-audit.toml` mba hanitsiana ny fetra na hanesorana fanamarinana manokana:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Omeo mazava tsara ilay rakitra:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Fiteny sy faritra

Ny fanampiana CLI, ny fitiliana, ary ny rafitry ny tatitra lahatsoratra/HTML dia manohana fiteny sy faritra 45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) tsy misy fiankinan-doha fanampiny. Ny famaritana ny fiteny dia manamarina ny `--lang` (samihafa amin'ny `--language`, izay misafidy ny fanontana Wikipedia), avy eo `LC_ALL`, `LC_MESSAGES`, ary `LANG`, ary miverina amin'ny `en`. Ny fanalahidy vokatra JSON sy ny lasitra wikitext dia tsy miova.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## API Python

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
