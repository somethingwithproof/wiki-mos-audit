Umugenzuzi w'ibanze wa [Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) ku nyandiko za Wikipedia.

## Impamvu iki gikoresho kiriho

Nandika kandi nkasukura inyandiko kuri Wikipedia. Si buri gihe, ariko bihagije ku buryo natangiye kubona ikintu gihoraho: buri gihe iyo nafunguraga inyandiko ngo nyitunganye, nasubiragamo urutonde rumwe mu mutwe. Mbese amatariki yanditse mu buryo bumwe? Hari amagambo adasobanutse (weasel words)? Hari uwibagiwe URLs zidafite imiterere mu nkomoko? Igice cya See also cyarabyibushye cyane? Ibice byo hasi bikurikiranye mu buryo bukwiye?

Nyuma y'inshuro ya gatatu cyangwa ya kane nshaka n'intoki ibibazo bimwe bigera ku icumi na bibiri bikurikirana, nanditse script. Iyo script yarakuze. Ubu igenzura ibintu birenga 30 nakoraga n'intoki, kandi igafata n'ibyo nashoboraga kwibagirwa ku mugoroba wo ku wa kabiri naniwe.

Iki ntikisimbura ubushishozi bw'umwanditsi. Ni igikoresho cyo gutoranya ibibazo byihutirwa. Kikwereka aho ureba, si icyo wandika.

## Ibyo kigenzura

**Imyandikire n'injyana**
- Amagambo adasobanutse (MOS:WEASEL), amagambo yo gukabya gushima (MOS:PEACOCK)
- Imvugo zishingiye ku gihe cya none ("recently", "currently") zisaza nabi
- Ibimenyetso by'inyandiko zakozwe na AI: gutanga inkomoko birenze urugero mu gihimba cy'inyandiko (WP:AISIGNS), imvugo imeze nk'igitekerezo bwite (WP:NOTESSAY)
- Ibimenyetso by'amagambo birebana na MOS:INDIGENOUS
- Imyandikire y'amazina y'indege ya MOS:AVIATION
- Amakuru y'abapfuye cyangwa abakomeretse adafite inkomoko ya MOS:MILITARY

**Imiterere**
- Uburebure bw'intangiriro n'umubare w'ibika (MOS:LEAD)
- Ikurikirana ry'ibice rigereranywa na MOS:LAYOUT
- Ibice bigufi cyangwa bitarimo amakuru ahagije
- Ibice bidafite inkomoko (amagambo 100+, nta `<ref>`)
- Ubwiyongere bukabije bw'igice cya See also
- URLs zo hanze zidafite imiterere mu gihimba cy'inyandiko
- Ubwinshi bwa templates z'amagambo yavuzwe n'abandi (quote templates)

**Inkomoko n'ibisobanuro**
- URLs zidafite imiterere imbere mu bimenyetso bya `<ref>` (nta cite template)
- Isuzuma ry'umubare ugenzura wa ISBN
- URLs zanditse nabi muri templates z'inkomoko
- Imiyoboro yo hanze itagikora (ihitamo ryihariye, ritinda)

**Ibyiciro n'imiyoboro**
- Ibyiciro bibura
- Ubwiza bw'ibyiciro (ibyiciro bike cyane, cyangwa byagutse bikabije)
- Gutahura imiyoboro itukura (wikilinks zerekeza ku nyandiko zitabaho)
- Ibyiciro bifite imiyoboro itukura
- Imiyoboro yerekeza ku mapaji yo gusobanura amazina ahuje (disambiguation)
- Gushyira imiyoboro myinshi bikabije (MOS:OVERLINK)

**Infobox**
- Umubare w'ibipimo (parameters) n'ubucucike bw'urutonde (gutahura ukwiyongera gukabije)
- Ibipimo bikunze kwitegwa bibura
- Ibimenyetso bya infobox ya MOS:MILHIST

**Ibindi**
- Ubwiza bw'incamake ngufi (ibura, ndende cyane, ihura n'umutwe)
- Urutonde rwa templates zo gusana inyandiko (maintenance templates)
- Isuku y'imiyoboro y'imishinga ihuriweho (MOS:SISTER)
- Gutahura inyandiko z'imfubyi (nta wikilinks ziziyoboraho)
- Gushakisha inyandiko zishobora kuyiyoboraho (backlinks)
- Imiterere y'imitwe imeze nka timeline cyangwa liveblog

Buri gisuzuma gitanga ikibazo gifite urwego rw'ubukana (ruto/ruringaniye/rwo hejuru) hamwe no kugabanyirizwa amanota. Inyandiko itunganye ibona amanota 100.

## Gushyiramo

```
pip install .
```

mwparserfromhell ni umushinga w'ingenzi usabwa. Itanga isesengura rya wikitext rishingiye kuri AST kugira ngo itahure neza templates, imitwe, na wikilinks. Niba idashoboye kubakwa (nta C compiler ihari), igikoresho gihita gisubira ku isesengura rishingiye kuri regex mu buryo bwikora.

Mu iterambere:

```
pip install -e '.[dev]'
```

## Imikoreshereze

Genzura inyandiko ya Wikipedia iri ku murongo:

```
wiki-mos-audit "Gettysburg Address"
```

Genzura uhereye kuri URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Genzura dosiye ya wikitext iri kuri mudasobwa:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Genzura icyarimwe ububiko burimo dosiye za wikitext:

```
wiki-mos-audit --dir ./articles/
```

Simbuka amasuzuma ya API (uburyo bwo gukora utari kuri interineti):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Imiterere y'ibisubizo

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Amasuzuma y'amahitamo

Aya afunzwe ku buryo fatizo kubera ko atinda cyangwa akenera interineti:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Gukosora mu buryo bwikora

Ibisubizo byo gukosora byoroshye kandi bifite umutekano (imyanya y'ubusa, imiterere y'imyandikire) bishobora gushyirwa mu bikorwa mu buryo bwikora:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Reba uko bizasa utarandika impinduka:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Uburyo bwo kugereranya (diff)

Gereranya wikitext iri kuri mudasobwa na verisiyo iri ku murongo:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Igenamiterere

Kora dosiye ya `.wiki-mos-audit.toml` kugira ngo uhindure imipaka cyangwa uhagarike amasuzuma amwe n'amwe:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Uyitange mu buryo bugaragara:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Gushyira mu ndimi

Ubufasha ku murongo w'amabwiriza, ubutumwa bw'isuzuma, n'ibice bigize raporo ya text/HTML bishyigikira indimi 45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) nta yindi mishinga y'inyongera ikenewe. Ihitamo ry'ururimi risuzuma `--lang` (itandukanye na `--language`, ihitamo ururimi rw'ububiko bwa Wikipedia), hagakurikiraho `LC_ALL`, `LC_MESSAGES`, na `LANG`, hanyuma rigasubira kuri `en`. Imfunguzo z'ibisubizo bya JSON na templates za wikitext biguma uko biri.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## Python API

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
