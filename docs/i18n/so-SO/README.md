Hantidhawre marxaladda koowaad ah oo [Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) u sameeya maqaallada Wikipedia.

## Sababta uu u jiro

Waxaan wax ka tafatiraa Wikipedia. Ma aha joogto, laakiin si ku filan oo aan u bilaabay inaan dareemo qaab soo noqnoqda: mar kasta oo aan furo maqaal si aan u nadiifiyo, waxaan maskaxda ka marayay isla liis hubin ah. Taariikhuhu ma iswaafaqsan yihiin? Ma jiraan ereyo aan caddayn (weasel words)? Qof ma kaga tegay URL-yo qaawan tixraacyada? Qaybta "See also" ma barartay? Qaybaha hoose ee maqaalku ma ku jiraan siday u kala horreeyaan?

Ka dib markii saddexaad ama afraad ee aan gacanta ku baarayay isla darsin dhibaatooyin ah oo isku xiga, waxaan qoray qoraal-hawleed (script). Qoraalkaasi wuu koray. Hadda wuxuu hubiyaa in ka badan 30 shay oo aan gacanta ku samayn jiray, wuxuuna qabtaa waxyaabo aan seegi lahaa fiid Talaado ah oo aan daallan ahay.

Tani ma beddesho go'aanka tafatiraha. Waa qalab kala-saarid (triage). Wuxuu kuu sheegaa meesha aad eegto, ee kuma sheego waxa aad qorto.

## Waxa uu hubiyo

**Qaabka iyo codka qoraalka**
- Ereyada aan caddayn (MOS:WEASEL), ereyada buunbuuninta ah (MOS:PEACOCK)
- Weedhaha wakhtiga ee isbeddela ("dhawaan", "hadda") ee si dhakhso ah u gabooba
- Calaamadaha nuxurka ay AI samaysay: u-tiirin xad-dhaaf ah oo ku jirta qoraalka dhexdiisa (WP:AISIGNS), weedho u eg maqaal-ra'yi (WP:NOTESSAY)
- Calaamadaha ereybixinta ee MOS:INDIGENOUS
- Qaabaynta magacaabista ee MOS:AVIATION
- Bayaannada khasaaraha ee aan tixraaca lahayn ee MOS:MILITARY

**Qaab-dhismeedka**
- Dhererka hordhaca (lead) iyo tirada cutubyada (MOS:LEAD)
- Kala-horreynta qaybaha iyadoo la barbardhigayo MOS:LAYOUT
- Qaybaha gaaban ama aan si buuxda loo horumarin
- Qaybaha aan tixraaca lahayn (100+ erey, lahayn `<ref>`)
- Bararka qaybta See also
- URL-yada dibadda ee qaawan ee ku jira jirka maqaalka
- Cufnaanta qaab-dhismeedka xigashada (quote template)

**Tixraacyada iyo xigashooyinka**
- URL-yada qaawan ee ku jira gudaha calaamadaha `<ref>` (iyadoon lahayn template xigasho)
- Xaqiijinta lambarka hubinta ee ISBN
- URL-yada qaldan ee ku jira template-yada xigashada
- Xiriiriyeyaasha dibadda ee dhintay (ikhtiyaari ah, gaabis ah)

**Qaybaha (Categories) iyo xiriiriyeyaasha**
- Qaybaha maqan
- Tayada qaybaha (qaybo ku filan lahayn, ama aad u ballaaran)
- Ogaanshaha xiriiriyeyaasha cas (wikilinks u tilmaamaya maqaallo aan jirin)
- Qaybaha xiriiriyaha cas leh
- Xiriiriyeyaasha boggaga kala-soocidda (disambiguation pages)
- Xiriirinta xad-dhaafka ah (MOS:OVERLINK)

**Infobox**
- Tirada cabbirrada (parameters) iyo cufnaanta liiska (ogaanshaha bararka)
- Cabbirrada caadi ahaan la filayo ee maqan
- Calaamadaha infobox ee MOS:MILHIST

**Waxyaabo kale**
- Tayada sharraxaadda gaaban (maqan, aad u dheer, la mid ah cinwaanka)
- Liiska template-yada dayactirka
- Nadaafadda xiriiriyeyaasha mashaariicda walaalaha ah (MOS:SISTER)
- Ogaanshaha maqaallada agoonta ah (aan lahayn wikilinks soo gala)
- Helitaanka xiriiriyeyaasha dib-u-soo-noqon kara (potential backlinks)
- Qaababka cinwaannada jadwalka wakhtiga/liveblog-ga

Hubin kasta waxay soo saartaa arrin leh heerka darnaanta (hoose/dhexdhexaad/sare) oo leh dhibco laga jaro. Maqaal nadiif ahi wuxuu helaa 100.

## Rakibidda

```
pip install .
```

mwparserfromhell waa ku-tiirsanaan loo baahan yahay. Waxay bixisaa kala-qaadista wikitext ee ku salaysan AST si si sax ah loogu ogaado template-yada, cinwaannada, iyo wikilinks-ka. Haddii aan la isku dubbaridi karin (haddii aan la helin C compiler), qalabku wuxuu si toos ah ugu noqdaa kala-qaadista ku salaysan regex.


## Isticmaalka

Hantidhawr ku samee maqaal Wikipedia oo toos ah:

```
wiki-mos-audit "Gettysburg Address"
```

Hantidhawr ka samee URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Hantidhawr ku samee fayl wikitext oo maxalli ah:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Hantidhawr wadareed ku samee galka ay ku jiraan faylal wikitext ah:

```
wiki-mos-audit --dir ./articles/
```

Ka bood hubinnada API (habka khadka ka baxsan):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Qaababka wax-soo-saarka

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Hubinnada ikhtiyaariga ah

Kuwani si caadi ah way u dansan yihiin sababtoo ah way gaabis yihiin ama waxay u baahan yihiin gelitaan shabakad:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Hagaajinta tooska ah

Hagaajinta farsamo ee ammaanka ah (meelaha bannaan, qaabaynta) waxaa loo dabaqi karaa si toos ah:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Hore u eeg adigoon waxba qorin:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Habka isbarbardhigga (Diff mode)

Isbarbardhig wikitext-ka maxalliga ah iyo nooca tooska ah:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Habaynta

Samee fayl `.wiki-mos-audit.toml` ah si aad u hagaajiso xuduudaha ama u damiso hubinno gaar ah:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Si cad u gudbi:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Luqadeynta

Caawimaadda CLI, baaritaannada, iyo qaabka warbixinta qoraalka/HTML waxay taageeraan 45 luqadood (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) iyadoon loo baahnayn ku-tiirsanaan dheeraad ah. Xallintu waxay hubisaa `--lang` (oo ka duwan `--language`, taas oo doorata daabacaadda Wikipedia), ka dib `LC_ALL`, `LC_MESSAGES`, iyo `LANG`, iyadoo ku noqonaysa `en`. Furayaasha wax-soo-saarka JSON iyo template-yada wikitext lama beddelo.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## Python API

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
