Mkaguzi wa hatua ya kwanza wa [Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) kwa makala za Wikipedia.

## Kwa nini hii ipo

Mimi huhariri Wikipedia. Si mara kwa mara sana, lakini vya kutosha kiasi kwamba nilianza kugundua mtindo: kila nilipofungua makala ili kuisafisha, nilikuwa nikikagua orodha ileile akilini. Je, tarehe zinafanana? Kuna maneno ya kukwepa uwajibikaji? Kuna mtu aliacha URL tupu kwenye marejeleo? Je, sehemu ya See also imejaa kupita kiasi? Je, sehemu za chini ya makala ziko katika mpangilio sahihi?

Baada ya mara ya tatu au ya nne kukagua kwa mkono matatizo yaleyale kumi na mawili mfululizo, niliandika hati. Hati hiyo ilikua. Sasa inakagua mambo 30+ niliyokuwa nikiyafanya kwa mkono, na inakamata vitu ambavyo ningevikosa Jumanne jioni nikiwa nimechoka.

Hii si mbadala wa uamuzi wa mhariri. Ni zana ya kuchuja awali. Inakuambia mahali pa kuangalia, si cha kuandika.

## Kinachokagua

**Mtindo na sauti**
- Maneno ya kukwepa uwajibikaji (MOS:WEASEL), maneno ya kujigamba (MOS:PEACOCK)
- Maneno ya wakati wa kulinganisha ("recently", "currently") yanayopitwa na wakati haraka
- Ishara za maudhui yaliyotengenezwa na AI: uwekaji wa marejeleo kupita kiasi katika maandishi makuu (WP:AISIGNS), misemo inayofanana na insha (WP:NOTESSAY)
- Alama za istilahi za MOS:INDIGENOUS
- Muundo wa majina ya MOS:AVIATION
- Kauli za vifo za MOS:MILITARY zisizo na marejeleo

**Muundo**
- Urefu wa utangulizi na idadi ya aya (MOS:LEAD)
- Mpangilio wa sehemu dhidi ya MOS:LAYOUT
- Sehemu fupi au zisizoendelezwa vya kutosha
- Sehemu zisizo na marejeleo (maneno 100+, hakuna `<ref>`)
- Kujazwa kupita kiasi kwa sehemu ya See also
- URL za nje zilizo tupu katika mwili wa makala
- Msongamano wa violezo vya nukuu

**Marejeleo na manukuu**
- URL tupu ndani ya lebo za `<ref>` (bila kiolezo cha cite)
- Uthibitishaji wa tarakimu ya ukaguzi ya ISBN
- URL zilizoharibika katika violezo vya manukuu
- Viungo vya nje vilivyokufa (kwa kuchagua, ni polepole)

**Kategoria na viungo**
- Kategoria zilizokosekana
- Ubora wa kategoria (kategoria chache mno, pana kupita kiasi)
- Utambuzi wa viungo vyekundu (viungo vya wiki kwenda kwenye makala zisizokuwepo)
- Kategoria zenye viungo vyekundu
- Viungo vya kurasa za kutofautisha maana
- Uwekaji viungo kupita kiasi (MOS:OVERLINK)

**Infobox**
- Idadi ya vigezo na msongamano wa orodha (utambuzi wa ujazaji kupita kiasi)
- Vigezo vinavyotarajiwa kwa kawaida ambavyo vimekosekana
- Ishara za infobox ya MOS:MILHIST

**Nyingine**
- Ubora wa maelezo mafupi (yamekosekana, marefu mno, yanafanana na kichwa)
- Orodha ya violezo vya matengenezo
- Usafi wa viungo vya miradi dada (MOS:SISTER)
- Utambuzi wa makala yatima (hakuna viungo vya wiki vinavyoingia)
- Ugunduzi wa viungo vya nyuma vinavyoweza kuongezwa
- Mifumo ya vichwa vya habari vya ratiba ya matukio/liveblog

Kila ukaguzi hutoa tatizo lenye kiwango cha ukali (low/medium/high) pamoja na punguzo la alama. Makala safi hupata alama 100.

## Usakinishaji

```
pip install .
```

mwparserfromhell ni kitegemezi kinachohitajika. Hutoa uchanganuzi wa wikitext unaotegemea AST kwa utambuzi sahihi wa violezo, vichwa vya habari, na viungo vya wiki. Iwapo haiwezi kukusanywa (hakuna kikusanyaji cha C kinachopatikana), zana hurudi kiotomatiki kwenye uchanganuzi unaotegemea regex.

Kwa uendelezaji:

```
pip install -e '.[dev]'
```

## Matumizi

Kagua makala ya Wikipedia ya moja kwa moja:

```
wiki-mos-audit "Gettysburg Address"
```

Kagua kutoka kwa URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Kagua faili ya wikitext ya ndani:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Kagua kwa pamoja saraka ya faili za wikitext:

```
wiki-mos-audit --dir ./articles/
```

Ruka ukaguzi wa API (hali ya nje ya mtandao):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Miundo ya matokeo

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Ukaguzi wa hiari

Hizi zimezimwa kwa chaguo-msingi kwa sababu ni za polepole au zinahitaji ufikiaji wa mtandao:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Urekebishaji otomatiki

Marekebisho salama ya kimitambo (nafasi tupu, uumbizaji) yanaweza kutumika kiotomatiki:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Hakiki bila kuandika:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Hali ya tofauti

Linganisha wikitext ya ndani na toleo la moja kwa moja:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Usanidi

Tengeneza faili ya `.wiki-mos-audit.toml` ili kurekebisha viwango au kuzima ukaguzi mahususi:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Ipitishie waziwazi:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Ujanibishaji

Usaidizi wa CLI, uchunguzi, na kiunzi cha ripoti ya maandishi/HTML unasaidia lugha 45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) bila vitegemezi vya ziada. Utatuzi hukagua `--lang` (tofauti na `--language`, ambayo huchagua toleo la Wikipedia), kisha `LC_ALL`, `LC_MESSAGES`, na `LANG`, na kurudi kwenye `en`. Funguo za matokeo ya JSON na violezo vya wikitext hubaki bila kubadilika.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## API ya Python

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
