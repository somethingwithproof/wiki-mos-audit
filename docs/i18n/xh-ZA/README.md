Umphicothi wokuqala we-[Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) wamanqaku e-Wikipedia.

## Kutheni oku kukho

Ndihlela i-Wikipedia. Hayi ngalo lonke ixesha, kodwa ngokwaneleyo ukuba ndiqale ukuqaphela ipateni: ngalo lonke ixesha ndivula inqaku ukuze ndilicoce, bendisenza uluhlu olufanayo engqondweni. Ngaba imihla iyahambelana? Ngaba kukho amazwi angacacanga (weasel words)? Ngaba kukho umntu oshiye ii-URL ezingenasakhelo kwizalathiso? Ngaba icandelo elithi See also lidumbile? Ngaba amacandelo asezantsi alandelelana ngendlela efanelekileyo?

Emva kwesihlandlo sesithathu okanye sesine ndihlolisisa ngesandla iingxaki ezifanayo ezilishumi elinambini ngokulandelelana, ndabhala iskripthi. Eso skripthi sakhula. Ngoku sihlola izinto ezingaphezu kwama-30 ebendizenza ngesandla, kwaye sibamba izinto ebendingaziphosa ngorhatya lwangolweSibini ndidiniwe.

Oku asiyondawo yokutshintsha ugwebo lomhleli. Sisixhobo sokuhlela ngokubaluleka (triage). Sikuxelela apho kufuneka ukhangele khona, hayi oko kufuneka ukubhale.

## Oko ikuhlolayo

**Isitayile nethoni**
- Amazwi angacacanga (MOS:WEASEL), amagama okuzigwagwisa (MOS:PEACOCK)
- Imibinzana yexesha elinxulumeneyo ("recently", "currently") ephelelwa lixesha kakubi
- Iimpawu zomxholo owenziwe yi-AI: unikezelo olugqithisileyo lwemithombo kumbhalo oyintloko (WP:AISIGNS), ukubhala ngokungathi sisincoko (WP:NOTESSAY)
- Iiflegi zesigama ze-MOS:INDIGENOUS
- Ufomatho lweempawu ze-MOS:AVIATION
- Iingxelo ze-MOS:MILITARY zokufa okanye ukwenzakala ezingenasalathiso

**Ulwakhiwo**
- Ubude besingeniso nenani lemihlathi (MOS:LEAD)
- Ukulandelelana kwamacandelo ngokuchasene ne-MOS:LAYOUT
- Amacandelo amafutshane okanye angaphuhliswanga ngokwaneleyo
- Amacandelo angenazalathiso (amagama ali-100+, ngaphandle kwe-`<ref>`)
- Ukudumba kwecandelo elithi See also
- Ii-URL zangaphandle ezingenasakhelo kumbhalo oyintloko wenqaku
- Ubuninzi beethempleyithi zeengcaphuno

**Izalathiso neengcaphuno**
- Ii-URL ezingenasakhelo ngaphakathi kweethegi ze-`<ref>` (akukho thempleyithi yengcaphuno)
- Uqinisekiso lwedijithi yokuhlola ye-ISBN
- Ii-URL ezingalunganga kwiithempleyithi zezalathiso
- Amakhonkco angaphandle afileyo (khetha ukungena, ayacotha)

**Iindidi namakhonkco**
- Iindidi ezingekhoyo
- Umgangatho weendidi (iindidi ezimbalwa kakhulu, okanye ezibanzi kakhulu)
- Ukubhaqwa kwamakhonkco abomvu (amakhonkco e-wiki aya kumanqaku angekhoyo)
- Iindidi zamakhonkco abomvu
- Amakhonkco aya kumaphepha okucacisa
- Ukudibanisa ngokugqithisileyo (MOS:OVERLINK)

**I-Infobox**
- Inani leeparamitha kunye nobuninzi boluhlu (ukubhaqa ukudumba)
- Iiparamitha ezidla ngokulindelwa ezingekhoyo
- Iimpawu ze-infobox ze-MOS:MILHIST

**Okunye**
- Umgangatho wenkcazo emfutshane (ayikho, inde kakhulu, ifana nesihloko)
- Uluhlu lweethempleyithi zolondolozo
- Ucoceko lwamakhonkco eeprojekthi ezihambisanayo (MOS:SISTER)
- Ukubhaqwa kwamanqaku aziinkedama (akukho makhonkco e-wiki angenayo)
- Ukufunyanwa kwamakhonkco anokubuya
- Iipateni zezihloko zomgca wexesha okanye i-liveblog

Itshekhi nganye ivelisa ingxaki enenqanaba lobuzaza (eliphantsi/eliphakathi/eliphezulu) kunye nokutsalwa kwamanqaku. Inqaku elicocekileyo lifumana amanqaku ali-100.

## Ukusetyenziswa

Phicotha inqaku elisebenzayo le-Wikipedia:

```
wiki-mos-audit "Gettysburg Address"
```

Phicotha ukusuka kwi-URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Phicotha ifayile ye-wikitext yasekhaya:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Phicotha ngobuninzi uvimba weefayile ze-wikitext:

```
wiki-mos-audit --dir ./articles/
```

Tsiba iitshekhi ze-API (imowudi yokungabikho kwi-intanethi):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Iifomathi zeziphumo

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Iitshekhi ezinganyanzelekanga

Ezi zicinyiwe ngokwendalo kuba ziyacotha okanye zifuna ufikelelo lwenethiwekhi:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Ukulungisa ngokuzenzekelayo

Ukulungiswa okukhuselekileyo kwematshini (izithuba ezimhlophe, ufomatho) kunokusetyenziswa ngokuzenzekelayo:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Jonga kuqala ngaphandle kokubhala:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Imowudi ye-Diff

Thelekisa i-wikitext yasekhaya nenguqulelo esebenzayo:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Useto

Dala ifayile ethi `.wiki-mos-audit.toml` ukuze ulungelelanise imida okanye ucime iitshekhi ezithile:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Yidlulise ngokucacileyo:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Uguqulelo lweelwimi

Uncedo lwe-CLI, ukuxilongwa, kunye nolwakhiwo lwengxelo yombhalo/HTML zixhasa iilwimi ezingama-45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) ngaphandle kwemfuneko yokongeza ezinye iipakethi. Ukukhethwa kolwimi kuhlola `--lang` (eyahlukileyo kwi-`--language`, ekhetha uhlelo lwe-Wikipedia), kulandele `LC_ALL`, `LC_MESSAGES`, kunye ne-`LANG`, kubuyele kwi-`en`. Izitshixo zeziphumo ze-JSON kunye neethempleyithi ze-wikitext azitshintshi.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## I-Python API

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
