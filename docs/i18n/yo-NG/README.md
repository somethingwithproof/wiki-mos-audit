Olùṣàyẹ̀wò [Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) ìgbésẹ̀-àkọ́kọ́ fún àwọn àpilẹ̀kọ Wikipedia.

## Ìdí tí èyí fi wà

Mo máa ń ṣàtúnṣe Wikipedia. Kì í ṣe nígbà gbogbo, ṣùgbọ́n ó tó bẹ́ẹ̀ tí mo fi bẹ̀rẹ̀ sí í ṣàkíyèsí ìlànà kan: ní gbogbo ìgbà tí mo bá ṣí àpilẹ̀kọ kan láti tún un ṣe, mo ń ṣe àyẹ̀wò àtòkọ ọkàn kan náà. Ṣé àwọn déètì bá ara wọn mu? Ṣé àwọn ọ̀rọ̀ àṣejù aláìdánilójú (weasel words) wà? Ṣé ẹnìkan fi URL lásán sílẹ̀ nínú àwọn ìtọ́kasí? Ṣé apá "See also" kún jù? Ṣé àwọn apá ìsàlẹ̀ wà ní ètò tó tọ́?

Lẹ́yìn ìgbà kẹta tàbí kẹrin tí mo fi ọwọ́ ṣàyẹ̀wò àwọn ìṣòro méjìlá kan náà léra wọn, mo kọ ìwé-àṣẹ kan. Ìwé-àṣẹ náà dàgbà. Nísinsìnyí ó ń ṣàyẹ̀wò ohun tó ju 30 lọ tí mo ń ṣe pẹ̀lú ọwọ́, ó sì ń mú àwọn nǹkan tí màá fò ré ní ìrọ̀lẹ́ Ọjọ́ Ìṣẹ́gun tí àárẹ̀ bá mú mi.

Èyí kì í ṣe ìrọ́pò fún ìdájọ́ olóòtú. Ó jẹ́ irinṣẹ́ ìṣàṣàyàn ìṣòro. Ó ń sọ ibi tí o yẹ kí o wò fún ọ, kì í ṣe ohun tí o yẹ kí o kọ.

## Ohun tí ó ń ṣàyẹ̀wò

**Àṣà ìkọ̀wé àti ohùn**
- Àwọn ọ̀rọ̀ àṣejù aláìdánilójú (MOS:WEASEL), àwọn ọ̀rọ̀ ìgbéraga àṣejù (MOS:PEACOCK)
- Àwọn ọ̀rọ̀ àkókò ìbátan ("recently", "currently") tí wọ́n ń di àtijọ́ kíákíá
- Àwọn àmì àkóónú tí AI ṣẹ̀dá: ìtọ́kasí àṣejù nínú ara ọ̀rọ̀ (WP:AISIGNS), ìkọ̀wé bíi àròkọ (WP:NOTESSAY)
- Àwọn àsíá ọ̀rọ̀ MOS:INDIGENOUS
- Ìṣètò orúkọ MOS:AVIATION
- Àwọn gbólóhùn ikú tàbí ìpalára aláìsí ìtọ́kasí MOS:MILITARY

**Ìṣètò**
- Gígùn apá ìbẹ̀rẹ̀ àti iye ìpínrọ̀ (MOS:LEAD)
- Ìtòlẹ́sẹẹsẹ àwọn apá lòdì sí MOS:LAYOUT
- Àwọn apá kúkúrú tàbí tí kò tíì dàgbà tó
- Àwọn apá aláìsí ìtọ́kasí (ọ̀rọ̀ 100+, kò sí `<ref>`)
- Kíkún jù ti apá "See also"
- Àwọn URL òde lásán nínú ara àpilẹ̀kọ
- Ìwọ̀n àwòkọ́ṣe ọ̀rọ̀ àsọyé (quote template)

**Àwọn ìtọ́kasí àti àfọ̀ṣẹ**
- Àwọn URL lásán nínú àwọn àmì `<ref>` (kò sí àwòkọ́ṣe cite)
- Ìfìdímúlẹ̀ nọ́ńbà àyẹ̀wò ISBN
- Àwọn URL tí kò dára nínú àwọn àwòkọ́ṣe ìtọ́kasí
- Àwọn ìjápọ̀ òde tó ti kú (àṣàyàn, ó ń lọ́ra)

**Àwọn ẹ̀ka àti àwọn ìjápọ̀**
- Àwọn ẹ̀ka tí ó sọnù
- Dídára ẹ̀ka (àìtó ẹ̀ka, gbòòrò jù)
- Ìwárí ìjápọ̀-pupa (àwọn wikilink sí àpilẹ̀kọ tí kò sí)
- Àwọn ẹ̀ka ìjápọ̀-pupa
- Àwọn ìjápọ̀ ojú-ìwé ìyànjú ìtumọ̀ (disambiguation)
- Ìjápọ̀ àṣejù (MOS:OVERLINK)

**Àpótí àlàyé (Infobox)**
- Iye pàrámítà àti ìwọ̀n àtòkọ (ìwárí kíkún jù)
- Àwọn pàrámítà tí a sábà ń retí tí wọ́n sọnù
- Àwọn àmì infobox ti MOS:MILHIST

**Àwọn mìíràn**
- Dídára àpèjúwe kúkúrú (ó sọnù, ó gùn jù, ó bá àkọlé mu)
- Àkójọ àwọn àwòkọ́ṣe ìtọ́jú
- Ìmọ́tótó ìjápọ̀ iṣẹ́-àkànṣe ẹgbẹ́ (MOS:SISTER)
- Ìwárí àpilẹ̀kọ aláìlẹ́bí (kò sí wikilink tó ń wọlé)
- Ìwárí àwọn ìjápọ̀ padà tó ṣeé ṣe
- Àwọn àpẹẹrẹ àkọlé ìtàn-àkókò/ìròyìn tààrà

Àyẹ̀wò kọ̀ọ̀kan ń mú ìṣòro tí a fún ní ìwọ̀n líle (kéré/àárín/ga) jáde pẹ̀lú ìdínkù máàkì. Àpilẹ̀kọ tó mọ́ tónítóní gba máàkì 100.

## Ìfisórí

```
pip install .
```

mwparserfromhell jẹ́ ìgbẹ́kẹ̀lé tí a nílò. Ó ń pèsè ìtúpalẹ̀ wikitext tó dá lórí AST fún ìwárí àwòkọ́ṣe, àkọlé, àti wikilink tó péye. Tí a kò bá lè kọ ọ́ (kò sí olùkójọpọ̀ C tó wà), irinṣẹ́ náà yóò padà sí ìtúpalẹ̀ tó dá lórí regex fúnra rẹ̀.

Fún ìdàgbàsókè:

```
pip install -e '.[dev]'
```

## Ìlò

Ṣàyẹ̀wò àpilẹ̀kọ Wikipedia tààrà:

```
wiki-mos-audit "Gettysburg Address"
```

Ṣàyẹ̀wò láti inú URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Ṣàyẹ̀wò fáìlì wikitext abẹ́lé:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Ṣàyẹ̀wò ìdìpọ̀ àpótí fáìlì ti àwọn fáìlì wikitext:

```
wiki-mos-audit --dir ./articles/
```

Fò àwọn àyẹ̀wò API (ipò láìsí íńtánẹ́ẹ̀tì):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Àwọn ọ̀nà àbájáde

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Àwọn àyẹ̀wò àṣàyàn

Àwọn wọ̀nyí wà ní pípa ní àìyípadà nítorí wọ́n ń lọ́ra tàbí wọ́n nílò ìsopọ̀ nẹ́tíwọ́ọ̀kì:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Àtúnṣe aládàáṣe

A lè lo àwọn àtúnṣe ẹ̀rọ tó wà ní ààbò (ààyè òfo, ìṣètò) fúnra rẹ̀:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Àwòkọ́ ṣáájú láìkọ sílẹ̀:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Ipò ìyàtọ̀ (Diff)

Fi wikitext abẹ́lé wé ẹ̀dà tààrà:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Ìṣètò

Ṣẹ̀dá fáìlì `.wiki-mos-audit.toml` kan láti ṣàtúnṣe àwọn ààlà tàbí pa àwọn àyẹ̀wò pàtó kan:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Fi í ránṣẹ́ ní gbangba:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Ìsọdèdè

Ìrànlọ́wọ́ ìlà-àṣẹ, àwọn ìwádìí, àti ìṣètò ojú ìròyìn ọ̀rọ̀/HTML ṣe àtìlẹ́yìn fún èdè agbègbè 45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) láìsí àfikún ìgbẹ́kẹ̀lé kankan. Ìyànjú ń ṣàyẹ̀wò `--lang` (tó yàtọ̀ sí `--language`, èyí tó ń yan ẹ̀dà Wikipedia), lẹ́yìn náà `LC_ALL`, `LC_MESSAGES`, àti `LANG`, ó sì ń padà sí `en`. Àwọn kọ́kọ́rọ́ àbájáde JSON àti àwọn àwòkọ́ṣe wikitext kò ní yípadà.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## API Python

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
