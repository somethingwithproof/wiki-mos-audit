Umcwaningi wokuqala we-[Manual of Style](https://en.wikipedia.org/wiki/Wikipedia:Manual_of_Style) wezindatshana ze-Wikipedia.

## Kungani lokhu kukhona

Ngihlela i-Wikipedia. Hhayi njalo, kodwa ngokwanele ukuthi ngaqala ukubona iphethini: njalo uma ngivula indatshana ukuze ngiyilungise, ngangilandela uhlu olufanayo engqondweni. Ingabe izinsuku zihambisana kahle? Kukhona amagama angenabo ubufakazi obuqondile (weasel words)? Kukhona oshiye ama-URL angenasakhiwo kumareferensi? Ingabe isigaba esithi See also sigcwele kakhulu? Ingabe izigaba zangezansi zihlelwe ngendlela efanele?

Ngemva kwesikhathi sesithathu noma sesine ngihlola ngesandla izinkinga eziyishumi nambili ezifanayo zilandelana, ngabhala umbhalo wekhodi (script). Lowo mbhalo wekhodi wakhula. Manje uhlola izinto ezingaphezu kuka-30 ebengizenza ngesandla, futhi ubamba izinto ebengingaziphutha kusihlwa ngoLwesibili ngikhathele.

Lokhu akuthathi indawo yokwahlulela komhleli. Kuyithuluzi lokuhlunga izinkinga (triage). Likutshela ukuthi ubheke kuphi, hhayi ukuthi ubhaleni.

## Okukuhlolayo

**Isitayela nephimbo**
- Amagama angenabo ubufakazi obuqondile (MOS:WEASEL), amagama okudumisa ngokweqile (MOS:PEACOCK)
- Izinkulumo zesikhathi ezincike esikhathini samanje ("recently", "currently") eziphelelwa isikhathi masinyane
- Izimpawu zokuqukethwe okwenziwe nge-AI: ukucaphuna ngokweqile embhalweni oyinhloko (WP:AISIGNS), ukubhala okufana nendaba (WP:NOTESSAY)
- Amafulegi amagama e-MOS:INDIGENOUS
- Ukufomethwa kwamagama ezindiza kwe-MOS:AVIATION
- Izitatimende zabalimalayo ezempini ezingacashuniwe ze-MOS:MILITARY

**Isakhiwo**
- Ubude besigaba sokuqala (lead) nenani lezigaba (MOS:LEAD)
- Ukuhleleka kwezigaba ngokuqhathanisa ne-MOS:LAYOUT
- Izigaba ezimfushane noma ezingathuthukiswanga ngokwanele
- Izigaba ezingenamareferensi (amagama angu-100+, akukho `<ref>`)
- Ukugcwala ngokweqile kwesigaba esithi See also
- Ama-URL angaphandle angenasakhiwo embhalweni oyinhloko wendatshana
- Ukuminyana kwamathempulethi ezingcaphuno

**Amareferensi nezingcaphuno**
- Ama-URL angenasakhiwo ngaphakathi kwamathegi e-`<ref>` (akukho thempulethi yokucaphuna)
- Ukuqinisekiswa kwenombolo yokuhlola ye-ISBN
- Ama-URL angakhiwanga kahle kumathempulethi okucaphuna
- Izixhumanisi zangaphandle ezingasasebenzi (kuyakhethwa, kuthatha isikhathi)

**Izigaba nezixhumanisi**
- Izigaba ezingekho
- Ikhwalithi yezigaba (ezinezimbalwa kakhulu, ezibanzi ngokweqile)
- Ukutholwa kwezixhumanisi ezibomvu (ama-wikilink aya ezindatshaneni ezingekho)
- Izigaba zezixhumanisi ezibomvu
- Izixhumanisi zamakhasi okucacisa amagama (disambiguation)
- Ukuxhumanisa ngokweqile (MOS:OVERLINK)

**I-Infobox**
- Inani lama-parameter nokuminyana kohlu (ukuthola ukugcwala ngokweqile)
- Ama-parameter avame ukulindelwa angekho
- Izimpawu ze-infobox ze-MOS:MILHIST

**Okunye**
- Ikhwalithi yencazelo emfushane (engekho, ende kakhulu, ifana nesihloko)
- Uhlu lwamathempulethi okunakekela
- Ukuhlanzeka kwezixhumanisi zamaphrojekthi angodadewabo (MOS:SISTER)
- Ukutholwa kwezindatshana eziyizintandane (akukho ma-wikilink angenayo)
- Ukutholwa kwezixhumanisi ezingaba khona ezibuyayo (backlinks)
- Amaphethini ezihloko zomugqa wesikhathi noma ze-liveblog

Ukuhlola ngakunye kukhiqiza udaba olunesilinganiso sobukhulu (phansi/phakathi/phezulu) kanye nokudonswa kwamaphuzu. Indatshana ehlanzekile ithola amaphuzu angu-100.

## Ukusetshenziswa

Cwaninga indatshana ephilayo ye-Wikipedia:

```
wiki-mos-audit "Gettysburg Address"
```

Cwaninga kusukela ku-URL:

```
wiki-mos-audit "https://en.wikipedia.org/wiki/Gettysburg_Address"
```

Cwaninga ifayela le-wikitext lasendaweni:

```
wiki-mos-audit --wikitext-file article_corrected.txt
```

Cwaninga ngenqwaba uhla lwemibhalo lwamafayela e-wikitext:

```
wiki-mos-audit --dir ./articles/
```

Yeqa izivivinyo ze-API (imodi engaxhunyiwe ku-inthanethi):

```
wiki-mos-audit --wikitext-file article.txt --offline
```

### Amafomethi okukhipha

```
wiki-mos-audit "Article" --format text   # default
wiki-mos-audit "Article" --format json
wiki-mos-audit "Article" --json          # shorthand
wiki-mos-audit "Article" --format html
```

### Izivivinyo ezikhethwayo

Lezi zivaliwe ngokuzenzakalelayo ngoba zihamba kancane noma zidinga ukufinyelela kunethiwekhi:

```
wiki-mos-audit "Article" --check-urls       # HEAD-check all cited URLs
wiki-mos-audit "Article" --check-orphan     # check for incoming wikilinks
wiki-mos-audit "Article" --check-backlinks  # find articles that mention but don't link here
```

### Ukulungisa ngokuzenzakalelayo

Ukulungisa okuphephile okuzenzakalelayo (izikhala, ukufometha) kungasetshenziswa ngokuzenzakalelayo:

```
wiki-mos-audit --wikitext-file article.txt --fix --output-wikitext-file article_fixed.txt
```

Buka kuqala ngaphandle kokubhala:

```
wiki-mos-audit --wikitext-file article.txt --fix --dry-run
```

### Imodi ye-Diff

Qhathanisa i-wikitext yasendaweni nenguqulo ephilayo:

```
wiki-mos-audit --wikitext-file article_corrected.txt --diff
```

### Ukucushwa

Yakha ifayela le-`.wiki-mos-audit.toml` ukuze ulungise imikhawulo noma uvale izivivinyo ezithile:

```toml
min_severity = "low"
disabled_checks = ["mos-aviation-style"]
max_lead_words = 300
short_section_words = 40
overlink_threshold = 4
```

Lidlulisele ngokucacile:

```
wiki-mos-audit "Article" --config .wiki-mos-audit.toml
```

### Ukuhunyushelwa ezilimini zendawo

Usizo lwe-CLI, ukuxilonga, nohlaka lombiko wombhalo/HTML lusekela izilimi zendawo ezingu-45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) ngaphandle kokudinga okunye okuncikene nakho. Ukukhethwa kolimi kuhlolwa ku-`--lang` (ehlukile ku-`--language`, ekhetha uhlelo lwe-Wikipedia), kulandele i-`LC_ALL`, i-`LC_MESSAGES`, ne-`LANG`, kubuyele ku-`en`. Okhiye bokukhipha be-JSON namathempulethi e-wikitext kuhlala kungashintshile.

```
wiki-mos-audit "Article" --lang de --wikitext-file article.txt
LANG=fr_FR.UTF-8 wiki-mos-audit --help
```

## I-Python API

```python
from wiki_mos_audit import audit_mos

report = audit_mos("Article Title", wikitext)
print(f"Score: {report.score}/100")
for issue in report.issues:
    print(f"[{issue.severity}] {issue.check_id}: {issue.message}")
```
